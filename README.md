# The Cut Lab

Modern, mobile-first barber shop landing page and style recommender.

## Features
- Black / gray premium aesthetic
- Mobile-first design for in-shop QR use
- Recommended cuts based on:
  - face shape
  - hair texture
  - maintenance style
  - desired aesthetic
  - free-form description input
- WhatsApp booking button
- Share recommendation button
- Works without tokens or external APIs

## Run locally
Open `index.html` directly in a browser.

## Customize
- Replace the WhatsApp number in the buttons and links.
- Update the names, prices, and cut catalog in `app.js`.
- Edit the branding, colors, and layout in `styles.css`.

## Notes
This version is intentionally built to run offline and avoid API token costs. It uses browser-side rule-based recommendations, which works well for a local barber shop MVP.
